# Aqanto Landing Page

Ren publik pitch-sida för Aqanto, ett AI-baserat bokföringsbolag.

## Lokal körning

```bash
python3 -m http.server 4173
```

Öppna sedan:

```text
http://localhost:4173/
```

## Lokal kontroll

```bash
node --check script.js
```

Sidan är avsiktligt fristående och innehåller bara publik Aqanto-copy, frontendkod och publika bildassets.
